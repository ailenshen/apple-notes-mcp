# Apple Notes MCP

A native Swift MCP server for Apple Notes. See `README.md` for usage. Maintain native formatting, edit notes in place and preserve their identities. For protocol, permissions, releases or signing, consult the relevant section of `docs/maintenance.md`.

Build with `swift build` and run `swift run NotesKitChecks unit`. Use throwaway notes for write tests. Use English for public issues, PRs and commits. Confirm issue actions with Ailen.
